*В разработке.*

## Навигация

| Клавиша | Действие |
|---------|----------|
| `gg` | Первая строка |
| `G` | Последняя строка |
| `0` | Начало строки |
| `$` | Конец строки |

## Редактирование

| Клавиша | Действие |
|---------|----------|
| `dd` | Вырезать всю строку |
| `yy` | Скопировать всю строку |
| `p` | Вставить ниже курсора |
| `u` | Отменить |

> **Паттерн:** Vi — это язык. `d` = delete, `y` = yank, `G` = конец файла.
> Как только видишь грамматику — остальное приходит само.
