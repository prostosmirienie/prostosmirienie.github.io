Vi wirkt feindselig — bis es klickt. Diese 11 Shortcuts sind der Moment.

## Modi

| Taste | Aktion |
|-------|--------|
| `i` | Einfügen vor dem Cursor |
| `a` | Einfügen nach dem Cursor |
| `Esc` | Zurück in den Normalmodus |

## Navigation

| Taste | Aktion |
|-------|--------|
| `gg` | Erste Zeile |
| `G` | Letzte Zeile |
| `0` | Zeilenanfang |
| `$` | Zeilenende |

## Bearbeitung

| Taste | Aktion |
|-------|--------|
| `dd` | Ganze Zeile ausschneiden |
| `yy` | Ganze Zeile kopieren |
| `p` | Unterhalb einfügen |
| `u` | Rückgängig |

> **Das Muster:** Vi ist eine Sprache. `d` = delete, `y` = yank, `G` = Dateiende.
> Wer die Grammatik erkennt, lernt den Rest von selbst.
